Pick a search type, choose a time window, enter your ID, and hit Search.

Tip: New traces take about 5 minutes to appear in Dynatrace. If your search returns nothing, wait a moment and try again.

How to search
Browser x-request-id search
  1. Open your browser's DevTools and go to the Network tab.
  2. Reproduce the issue.
  3. Click the failing network call.
  4. Under Request Headers, copy the x-request-id value and paste it into the search box above.
URL / URL path search
  1. In the Network tab, find the affected request.
  2. Copy any of: the full URL, just the hostname, or just the path (with or without a leading /).
  3. Paste it into the search box above and hit Search.
  4. From the results table, select the most relevant trace ID (based on your timestamp) to see the details.
RUM Session ID search
  1. In the Network tab, filter all requests by bf?type=js.
  2. Click any one of the matching requests.
  3. Go to the Payload tab and copy the string parameter next to vi.
  4. Paste it into the search box above to view the user session details.
